# Opera Ads SDK

Opera Ads SDK is an advertising SDK for Android applications, supporting multiple ad formats.

## Project Overview

The [Sample](https://github.com/operaads/android-sdk/tree/master/Sample) project is a sample project demonstrating how to integrate Opera Ads SDK in your own project.

## Core Features

Opera Ads SDK supports the following ad formats:

- **Native**: Supports image media content
- **Banner**: Banner ads in various sizes
- **Interstitial**: Full-screen interstitial ads
- **Rewarded**: Users receive rewards after watching
- **RewardedInterstitial**: Unlike rewarded ads, users aren't required to opt in to view a rewarded interstitial.
- **AppOpen**: Can be closed at any time, and are designed to be shown when your users bring your app to the foreground.

## Getting Started with Opera Ads

Refer to our [documentation](https://doc.adx.opera.com/ofs/android/) for step-by-step guides on integrating Opera Ads SDK in your app.
